# PhonePe-Transaction-Analysis

# 📱 PhonePe Transaction Analysis using SQL & Power BI

## 📌 Project Overview

This project analyzes **PhonePe transaction data** using **MySQL** and **Power BI** to uncover meaningful business insights related to customer behavior, transaction performance, spending patterns, and payment success rates.

The project demonstrates an end-to-end analytics workflow by writing SQL queries to answer business questions and presenting the results through an interactive Power BI dashboard.

---

# 🎯 Objectives

* Analyze customer transaction behavior.
* Measure platform performance using key metrics.
* Identify high-value customers.
* Monitor payment success and failed transactions.
* Visualize important KPIs through an interactive Power BI dashboard.

---

# 🛠️ Tech Stack

* **MySQL** – Data storage and SQL analysis
* **Power BI** – Dashboard creation and visualization
* **CSV Files** – Data source

# 🔍 Business Problems Solved Using SQL

The project answers the following business questions:

1. Calculate the total number of registered users.
2. Calculate the total number of transactions.
3. Calculate the total transaction value.
4. Find the average transaction amount.
5. Identify the highest-value transaction.
6. Calculate the overall payment success rate.
7. Find the average transaction amount for each payment service.
8. Calculate total spending for every user.
9. Identify the Top 10 highest-spending users.
10. Calculate the total number of transactions performed by each user.
11. Identify users who registered but never made a transaction.
12. Find the customer with the highest lifetime transaction value.
13. Calculate failed transactions for every user.
14. Analyze month-over-month revenue growth using SQL Window Functions.
15. Identify the most popular payment service.
16. Find users whose spending is above the average user spending.
17. Segment customers into High, Medium, and Low value groups using SQL CASE statements.
